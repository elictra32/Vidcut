# Vidcut

โปรแกรมตัดต่อวิดีโอบนเครื่องตัวเอง สำหรับตัดคลิปยาวภาษาไทยให้เหลือ 1–2 นาที ลง TikTok / YouTube

- ตัด Dead air (ช่วงเงียบ) อัตโนมัติ และเปิด/ปิดทีละช่วงได้
- สร้างซับภาษาไทยอัตโนมัติด้วย Whisper (รันบนเครื่อง ไม่ใช้ Token ไม่ส่งเสียงออกอินเทอร์เน็ต)
- แก้ข้อความ ปรับเวลา ย้ายตำแหน่ง และตั้งสไตล์ซับได้
- ส่งออก MP4 (ฝังซับ) + ไฟล์ `.srt` แยกตาม preset TikTok 9:16 หรือ YouTube 16:9

ทุกอย่างทำงานในเครื่อง ไฟล์ต้นฉบับไม่ถูกแก้ไขหรือคัดลอก

## ติดตั้ง (Windows 11)

1. ติดตั้ง Python 3.12: เปิด Terminal แล้วรัน `winget install Python.Python.3.12` (ถ้ามี Python 3.11/3.12/3.13 อยู่แล้วข้ามได้)
2. ดับเบิลคลิก **`setup.bat`** จะติดตั้ง ffmpeg (ผ่าน winget), สร้างสภาพแวดล้อม Python และลงไลบรารีให้
3. ดับเบิลคลิกไอคอน **Vidcut** บนเดสก์ท็อป (`setup.bat` สร้างให้ หรือดับเบิลคลิก **`Vidcut.vbs`** ในโฟลเดอร์) โปรแกรมเปิดเป็นหน้าต่างของมันเอง ไม่มีหน้าต่างดำ ไม่ต้องรันคำสั่งหรือเปิดค้างไว้ ปิดหน้าต่างแล้วโปรแกรมจะหยุดเองภายในไม่กี่วินาที แต่ถ้ายังมีงานส่งออกที่กำลังรันหรือรอคิวอยู่ มันจะทำต่อเบื้องหลังจนเสร็จแล้วค่อยปิดเอง (เปิดไอคอนอีกครั้งเพื่อดูความคืบหน้า) ปุ่ม **Quit** มุมขวาบนปิดโปรแกรมทันที (งานที่ค้างอยู่จะทำต่อเมื่อเปิดครั้งหน้า) ถ้าอยากเห็นข้อความของโปรแกรมเวลามีปัญหา ใช้ `run.bat` แทน (เปิดหน้าต่างดำค้างไว้) หรือดูไฟล์ `VidcutProjects\default\vidcut.log`

ครั้งแรกที่กด "สร้างซับอัตโนมัติ" โปรแกรมจะดาวน์โหลดโมเดล Whisper (`large-v3` ราว 3 GB) ครั้งเดียว

## วิธีใช้

1. **เพิ่มคลิป** กด "+ เพิ่มคลิป" แล้วเลือกไฟล์ (ถ้าหน้าต่างเลือกไฟล์ไม่ขึ้น ใช้ "วางพาธไฟล์แทน") ไฟล์ที่เบราว์เซอร์เล่นไม่ได้ (เช่น HEVC/MKV) จะถูกสร้างไฟล์พรีวิวให้ก่อน ซึ่งอาจนานสำหรับคลิปชั่วโมง
2. **ตัด Dead air** ที่แผง "ตัด Dead air" ปรับค่าแล้วกดปุ่ม จากนั้นดูแถบ "ตรวจช่วงที่ตัด": คลิกช่วงเขียวเพื่อตัดออก คลิกช่วงแดงเพื่อเอากลับมา เลื่อนล้อเมาส์เพื่อซูม ลากเพื่อเลื่อน
3. **เลือกช่วงที่จะใช้** เลื่อนไปจุดเริ่ม กด `I` (หรือ "ตั้ง In") แล้วไปจุดจบ กด `O` (หรือ "ตั้ง Out") ใช้ "เล่นช่วงที่เลือก" เพื่อตรวจ
4. **สร้างซับ** เลือกโมเดลแล้วกด "สร้างซับอัตโนมัติ" โปรแกรมถอดเสียงเฉพาะช่วงที่เลือก (บน CPU ใช้เวลาหลายนาที) ถ้าช้าไป เลือกโมเดล `medium` หรือ `small`
   **หรือนำเข้าซับจาก YouTube (เร็วกว่า ไม่ต้องรอ Whisper):** อัปโหลด**ไฟล์ต้นฉบับ** (ก่อนตัด Dead air) ขึ้น YouTube รอให้สร้างซับอัตโนมัติ แล้วที่ YouTube Studio → คำบรรยาย → ⋮ → ดาวน์โหลด → `.srt` จากนั้นกด "นำเข้าไฟล์ .srt" ที่แผงซับไตเติล โปรแกรมจะตัดแท็ก `[เสียงหัวเราะ]` เครื่องหมาย `>>` และคำอุทานล้วน ๆ (เออ, อือ, อ่ะ ...) ออก รวมประโยคที่ YouTube ตัดกลางคำ แล้วแบ่งบรรทัดตาม preset ค่าเริ่มต้นนำเข้าเฉพาะช่วง In/Out ที่เลือก เวลาในซับเป็นค่าประมาณระดับประโยค ปรับขอบบนไทม์ไลน์ได้ ถ้าซับเร็ว/ช้ากว่าเสียงสม่ำเสมอ ใช้ช่อง "เลื่อนเวลา" (ค่าบวก = ซับขึ้นช้าลง ใช้เมื่อซับขึ้นเร็วกว่าเสียง ค่าลบ = ซับขึ้นเร็วขึ้น) (ไฟล์ SRT ต้องมาจากไฟล์เดียวกับที่ใส่ในโปรแกรม)
5. **แก้ซับ** แก้ข้อความในรายการด้านซ้าย ลากขอบแถบซับบนไทม์ไลน์เพื่อปรับเวลา ลากซับบนภาพตัวอย่างเพื่อย้ายตำแหน่ง (ดับเบิลคลิกเพื่อคืนค่า) และปรับฟอนต์ (Sarabun, Prompt, Prompt Medium) สี ขอบ ที่แผง "สไตล์ซับ"
6. **ส่งออก** (ไฟล์ใหม่ไม่เขียนทับไฟล์เก่า จะได้ชื่อ `_2`, `_3` ... ต่อท้าย) ที่แผง "ส่งออก" เลือก**ชนิดไฟล์** (MP4/MOV/MKV/WebM), **คุณภาพ** (สูง/กลาง/เล็ก หรือกำหนดขนาดไฟล์เป้าหมายเป็น MB) และ**โฟลเดอร์ปลายทาง** ได้ โปรแกรมจะแสดงความยาวและ**ขนาดไฟล์โดยประมาณ (±15%)** ก่อนส่งออก ถ้าอยากต่อ**ปกหัว/ปกท้าย** ให้เพิ่มคลิปเข้ามาแล้วเปลี่ยนบทบาทของคลิปที่รายการซ้ายเป็น "ปกหัว" หรือ "ปกท้าย" (ตัดต่อตรง ๆ ไม่มีเอฟเฟกต์) ตอนส่งออกจะได้ ปกหัว + ช่วงที่เลือกจากคลิปหลัก + ปกท้าย และเวลาซับขยับตามให้เอง เลือก TikTok หรือ YouTube ถ้าคลิปเป็นแนวนอนแต่ส่งออก 9:16 เลือกกรอบภาพได้ ("เต็มภาพ + พื้นหลังเบลอ" หรือ "ครอปเต็มจอ" ซึ่งลากบนภาพเพื่อเลื่อนกรอบ) กด "ตรวจเฟรมจริง" เพื่อดูภาพที่จะได้จริงก่อน แล้วกด "ส่งออกวิดีโอ"

ภาพตัวอย่างในหน้าจอมีสัดส่วนเท่าไฟล์ที่ส่งออก และตำแหน่งซับเป็นเปอร์เซ็นต์ของกรอบนั้น แต่ตัวอย่างวาดด้วยเบราว์เซอร์ ส่วนไฟล์จริงวาดด้วย ffmpeg อาจต่างกันเล็กน้อย จึงมีปุ่ม "ตรวจเฟรมจริง"

คีย์ลัด: `Space` เล่น/หยุด · `I` / `O` ตั้งจุดเริ่ม/จบ · `←` `→` ถอย/เดินหน้า 1 วินาที (กด Shift = 5 วินาที)

## ฟีเจอร์เพิ่มเติม

หน้าจอโปรแกรมเป็นภาษาอังกฤษ (ชื่อปุ่มด้านล่างคือชื่อที่เห็นบนจอ) ส่วนซับที่ถอดเสียงและส่งออกยังเป็นภาษาไทย

- **Confirm cuts / Edit cuts**: ตรวจช่วงตัดของคลิปแล้วกด Confirm แถบตรวจจะพับเก็บ จะได้เพิ่มคลิปถัดไปต่อได้เลย กด Edit cuts เพื่อกลับมาแก้ (ถ้ารัน Detect and cut dead air ใหม่ ระบบจะถามยืนยันอีกครั้ง)
- **ตัดบนไทม์ไลน์**: ปุ่ม **+ Add clip** ที่แถบไทม์ไลน์เพิ่มคลิปต่อท้าย (Main clip) แล้วตัดได้เลย: **✂ Cut here** (กด `S`) แบ่งช่วงที่เพลย์เฮดอยู่เป็นสองท่อน, **Delete segment** (กด `Delete`) เอาท่อนใต้เพลย์เฮดออก, **Cut out In–Out** (กด `X`) ตัดช่วงระหว่าง In–Out ออก เส้นสีเหลืองบนไทม์ไลน์คือจุดแบ่งที่ยังไม่ได้ตัดอะไรออก ช่วงที่ตัดออกยังอยู่ในแถบ Review cuts คลิกเอากลับได้ และ `Ctrl+Z` ย้อนได้
- **Episode covers (ปกหัวอัตโนมัติ)**: แผง Episode covers ทำคลิปปกจากปกตัวอย่างของ THUS (โลโก้ พื้นหลัง เสียงเดิม) เปลี่ยนแค่ชื่อ EP และวันที่ ตั้งปกตัวอย่างอันหนึ่งเป็น Intro ก่อน (ความละเอียด 1920×1080 ยาวราว 3 วินาที) เลือกในช่อง "Copy the look of" เลือกวันที่ (ได้ข้อความไทยพร้อมปี พ.ศ. ให้) พิมพ์ชื่อ EP บรรทัดละ 1 อัน (ใส่ `ชื่อ | วันที่ ...` เพื่อกำหนดวันที่ของ EP นั้นเอง) แล้วกด Make covers ได้ปกเป็นคลิป Intro เรียงตามลำดับ (ถ้าติ๊ก Replace จะแทนที่ Intro เดิม ไฟล์เดิมไม่ถูกลบ) ไฟล์ปกเก็บที่ `VidcutProjects\default\covers` ตำแหน่งตัวอักษรและจังหวะค่อย ๆ ขึ้น/จางวัดจากปกตัวอย่างที่ส่งมา ใช้ฟอนต์ตามคู่มือแบรนด์ THUS: Montserrat สำหรับชื่อ EP และ Prompt Light สำหรับวันที่ (ขนาดและความกว้างตัวอักษรวัดแล้วตรงกับปกต้นฉบับ) ใช้ได้กับปกแบบนี้เท่านั้น ถ้าเปลี่ยนดีไซน์ปก ต้องปรับตำแหน่งใหม่
- **Queue (คิวงาน)**: ปุ่ม **Add to queue** ข้าง Export video และ Export all episodes ใส่งานเข้าคิวแทนการรันทันที แต่ละงานจำสถานะโปรเจกต์ ณ ตอนที่ใส่ (แก้ต่อทีหลังก็ไม่กระทบ) งานรันทีละอันตามลำดับ จัดการที่แผง Queue: เลื่อนขึ้น/ลง ยกเลิก หยุดชั่วคราว (Pause queue) และล้างที่เสร็จแล้ว คิวและโปรเจกต์ถูกบันทึกอัตโนมัติ ปิดโปรแกรมตอนมีงานค้างได้ เปิดใหม่แล้วงานที่ค้างจะทำต่อ (งานที่ค้างอยู่กลางคันจะเริ่มใหม่จากต้นงานนั้น) คิวรองรับ Export และ Episodes ส่วนสร้างซับ/สร้างปก ยังรันทันที
- **Undo / Redo**: ปุ่ม ↶ ↷ ที่แถบบน หรือ `Ctrl+Z` / `Ctrl+Y` ย้อนได้ทั้งการแก้ซับ ตัดช่วง สไตล์ โลโก้ และสิ่งที่งานเบื้องหลังเพิ่งทำ (เช่น สร้างซับ นำเข้าซับ ตัด Dead air) ขณะพิมพ์ในกล่องข้อความ `Ctrl+Z` จะย้อนตัวอักษรของกล่องนั้นตามปกติ
- **กรอกตัวเลขได้ทุกที่**: ตัวเลื่อนทุกอันมีช่องตัวเลขข้างกัน (ขนาด ตำแหน่ง ความโปร่งใส) พิมพ์ค่าที่ต้องการแล้วกด Enter หรือ Tab ซับแต่ละบรรทัดมีช่อง X / Y (เป็น % ของเฟรม เว้นว่าง = ตามสไตล์)
- **แก้ซับบนภาพตัวอย่าง**: ดับเบิลคลิกซับบนภาพเพื่อพิมพ์แก้ (Esc หรือ Ctrl+Enter เพื่อบันทึก Enter ขึ้นบรรทัดใหม่) ลากเพื่อย้าย เลื่อนล้อเมาส์เพื่อปรับขนาด
- **Re-wrap every subtitle**: ตั้งจำนวนตัวอักษรต่อบรรทัดและจำนวนบรรทัด แล้วกด Apply to all เพื่อจัดบรรทัดทุกซับใหม่ในครั้งเดียว (ตัดเฉพาะระหว่างคำ ซับที่ยาวเกินจะถูกแบ่งเป็นหลายซับ) ย้อนด้วย Ctrl+Z ได้
- **Delete all subtitles**: ลบซับทั้งหมดในครั้งเดียว (มีกล่องยืนยัน กู้คืนไม่ได้)
- **ซับรายบรรทัด**: ใต้ซับแต่ละบรรทัดมีจำนวนตัวอักษร แถบ Size ปรับขนาดเฉพาะบรรทัดนั้น (หรือเลื่อนล้อเมาส์บนซับในภาพตัวอย่าง) ปุ่ม Split แยกบรรทัดตรงเคอร์เซอร์ และ Merge ↓ รวมกับบรรทัดถัดไป
- **Reveal text as it's spoken** (แผง Subtitle style): ซับค่อย ๆ ขึ้นทีละตัวอักษรตามเวลาที่พูด ทั้งในภาพตัวอย่างและไฟล์ส่งออก เวลาแต่ละตัวอักษรเป็นการกระจายเท่า ๆ กันในบรรทัด ไม่ใช่เวลาจริงรายคำ
- **THUS logos**: ในแผง Logo / photo กด "THUS logos" เลือกแบบและสีได้เลย (Logo, Symbol, Symbol + name อย่างละ 6 สี: gradient, white, black, aubergine, lavender, orange) ทุกไฟล์เป็น PNG พื้นโปร่งใสที่แปลงจาก `Logo.ai` ของแบรนด์ อยู่ในโฟลเดอร์ `assets\\logos` (มีรูปรวม `_overview.png`) นำไปใช้นอกโปรแกรมได้ด้วย
- **Logo / photo**: เพิ่มโลโก้หรือรูป (PNG พื้นโปร่งใสดีที่สุด) ลากย้ายและเลื่อนล้อเมาส์ปรับขนาดบนภาพตัวอย่าง ตั้งความโปร่งใสและช่วงเวลา (วินาทีในไฟล์ที่ส่งออก) ได้ ภาพตัวอย่างแสดงรูปตลอด ช่วงเวลามีผลเฉพาะไฟล์ส่งออก
- **คุณภาพ Best value**: เข้ารหัสแบบคุณภาพคงที่ ไฟล์เล็กสุดโดยภาพคงเดิม และไม่เกิน 120% ของบิตเรตต้นฉบับ (ตัวเลขขนาดที่เห็นคือ "up to" เพดานสูงสุด) ส่วน High/Medium/Small เป็นสัดส่วน 120%/80%/50% ของบิตเรตต้นฉบับ ช่อง Target file size ใช้เฉพาะ Custom size
- **ชื่อไฟล์ที่ส่งออก**: ช่อง "File name" ในแผง Export ตั้งชื่อเองได้ (เว้นว่าง = ชื่อคลิปหลัก + preset) ส่วน Export all episodes ตั้งชื่อไฟล์ตามชื่อปกหัวของ EP นั้น เช่น `Candlestick and Price Pattern II P1.mp4` ถ้าไม่มีซับ จะไม่สร้างไฟล์ `.srt` เปล่า ๆ ให้ และไม่มีไฟล์อื่นปนในโฟลเดอร์ส่งออก
- **Split into episodes**: แบ่งงานยาวเป็น EP ละไม่เกินขนาดที่กำหนด (เช่น 500 MB) ด้วยจำนวน EP น้อยที่สุดที่คุณภาพยังชัด กด Plan episodes แล้วโปรแกรม**เข้ารหัสตัวอย่างสั้น ๆ 4 ช่วงจากคลิปจริง**เพื่อวัดขนาดจริง (ใช้เวลาราวครึ่งนาที) แทนการเดาจากค่าเพดาน ฉากนิ่งอย่างผู้สอนยืนหน้าสไลด์มักได้ไฟล์เล็กกว่าเพดานมาก จึงมักแบ่งน้อยลงหรือไม่ต้องแบ่ง ขนาดสูงสุดต่อ EP ยังถูกล็อกด้วยเพดานบิตเรตของตัวเข้ารหัส ตัดที่จุดที่ตัด Dead air ออก แต่ละ EP ใช้ปกหัวคนละอัน (ตั้งบทบาทคลิปเป็น Intro เรียงตามลำดับ ถ้ามีไม่พอจะใช้อันสุดท้ายซ้ำ) และปกท้ายเดียวกัน (บทบาท Outro) กด Plan episodes เพื่อดูแผน แล้ว Export all episodes ได้ไฟล์ `ชื่อ_tiktok_EP01`, `EP02` ... ตั้งเป้าที่ ~92% ของขนาดสูงสุด ถ้า EP ไหนเกินจะขึ้นสีแดง
- **Export ไฮไลต์หลายตัวพร้อมกัน**: ติ๊กเลือกช่วงที่ต้องการ (ทั้งแบบ Scan subtitles และ Find short shots) แล้วกด Export N checked as separate clips จะได้ไฟล์แยกคนละคลิป (ชื่อ `_HL01_…`) เข้าคิวทำทีละคลิปต่อกันไป ติ๊ก Add the intro/outro clips ถ้าอยากให้ทุกคลิปมีปกหัว/ท้าย
- **ปกหน้า/หลังแนวตั้ง (TikTok 1080×1920)**: ในแผง Episode covers เลือก Cover style = Vertical Vidcut วาดให้เองด้วยสี THUS (โลโก้ ชื่อตอนสีส้มในกล่องดำ วันที่) เลี่ยงโซนที่ปุ่ม/แคปชั่น TikTok ทับ และทำปกท้ายให้คู่กันได้ (แก้ข้อความได้) นี่เป็นดีไซน์ใหม่ที่ผมออกแบบเอง ไม่ใช่ของเดิม ถ้าอยากปรับเลย์เอาต์ บอกได้ ปกจะไม่มีเสียงเพลง (เสียงเงียบ)
- **ปรับสีคลิป**: แผง Colour (ฝั่งขวา) ปรับต่อคลิป: Warmth (ลดเหลือง/เพิ่มอุ่น), Tint, Brightness, Contrast, Colour strength พิมพ์ตัวเลขได้ มีปุ่มลัด Less yellow / Cooler / Warmer / Punchier / Brighter, Reset, และ Use on all clips ตัวอย่างในจอพรีวิวใกล้เคียงกับตอน Export แต่ไม่เหมือนเป๊ะ ถ้าอยากเห็นภาพจริงกด Check real frame ในแผง Export (สีเดียวกับไฟล์ที่ได้) ปกหัว/ท้ายปรับได้เหมือนกัน
- **ฟอนต์เพิ่ม**: เพิ่ม Kanit, Mitr, Bai Jamjuree, Chakra Petch, IBM Plex Sans Thai, Pridi (ลิขสิทธิ์ OFL แจกฟรี ใช้ในงานได้) ใช้ได้ทั้งปกและซับ ในแผง Episode covers > Fonts เลือกฟอนต์ปกหน้า (ชื่อ/วันที่) และปกหลังแยกกันได้ ชื่อฟอนต์ในรายการแสดงเป็นตัวอักษรของฟอนต์นั้นเอง
- **เริ่มจากไฟล์ที่ตัดมาแล้วได้เลย**: Add clip แล้วทำซับต่อได้ทันที ไม่ต้อง Detect dead air (แถบ Review cuts จะขึ้นเฉพาะหลังกด Detect)
- **ความเร็ว**: คลื่นเสียง/ความดังถอดครั้งเดียวต่อไฟล์ แล้วจำไว้ในดิสก์ (เร็วทันทีในครั้งต่อไป) และแก้ท่อนที่ทำให้แอปหน่วงเมื่อมีซับหลักพันบรรทัดหรือตัดเป็นร้อยท่อน
- **รวมช็อตไฮไลต์เป็นคลิปเดียว (Reel)**: กด Find short shots (for a reel) จะได้ทุกช็อตสั้นๆ ที่ด่า/เตือนสติ/ขำ ทั้งคลิป (ช็อตละไม่กี่วินาที ต่อเนื่องกันรวมเป็นช็อตเดียว) ติ๊กเลือกได้ ติ๊กทั้งหมวดได้ แล้วกด Make reel Timeline จะเหลือเฉพาะช็อตที่ติ๊ก (ส่วนที่เหลือไม่ได้หาย Ctrl+Z กู้คืนได้) Timeline มีแถบเลื่อนด้านล่างลากเลื่อนซ้ายขวาได้ (หรือ Shift+ล้อเมาส์) ตัวหาช็อตใช้คำในซับ จึงต้องมีซับก่อนและเป็นแค่ตัวช่วยคัดเบื้องต้น
- **Find highlights**: สแกนซับหาช่วงน่าสนใจ แยกหมวด Scolding / Wake-up call / Funny / Energetic จากคำในซับและความดังของเสียง (แก้รายการคำได้ที่ Word lists) ใช้ฟรีบนเครื่อง ผลเป็นตัวช่วยคัดเบื้องต้น ไม่ได้เข้าใจความหมายจริง ถ้าอยากให้ AI ช่วย: กด Copy transcript for AI (ได้ถอดเสียงพร้อมคำสั่ง) นำไปวางใน Claude แล้ววางคำตอบกลับที่ช่อง แล้วกด Read AI picks จากนั้น Preview หรือ Use as In/Out ได้ทุกช่วง
- **นำเข้าซับ .srt / .vtt / .sbv**: รับทั้งสามแบบ ถ้าซับทำจาก**วิดีโอต้นฉบับ** แต่คลิปที่ใส่ในโปรแกรมคือ**เวอร์ชันที่ตัด Dead air แล้ว** ให้เลือก "Made for the video BEFORE dead air was cut" แล้ว (ก) ถ้าคลิปนี้เคยถูก Export จากโปรแกรมนี้ โปรแกรมจำไว้ว่าตัดช่วงไหนออก (เก็บในโฟลเดอร์ `manifests` ของโปรเจกต์ ไม่ทิ้งไฟล์แปลก ๆ ไว้ข้างวิดีโอ) จะแปลงเวลาให้ตรงเป๊ะอัตโนมัติ หรือ (ข) เลือก "Choose the original video…" โปรแกรมจะเทียบเสียงของสองไฟล์เพื่อหาว่าตัดช่วงไหนออก (เวลา 60 นาทีประมาณ 20 วินาทีถึงหลายนาที) เทสต์กับเสียงสังเคราะห์ผ่าน แต่ยังไม่เคยลองกับเสียงพูดจริง ถ้าไม่ตรง ใช้ช่อง Time shift ช่วย

## ไฟล์อยู่ที่ไหน

- โปรเจกต์: `%USERPROFILE%\VidcutProjects\default\project.json`
- ไฟล์ที่ส่งออก: `%USERPROFILE%\VidcutProjects\default\exports\`
- เปลี่ยนที่เก็บ: ตั้งตัวแปร `VIDCUT_HOME` · เปลี่ยนพอร์ต: `VIDCUT_PORT`

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| `setup.bat` บอกไม่พบ ffmpeg หลังติดตั้ง | ปิดหน้าต่าง เปิดใหม่ แล้วรัน `setup.bat` อีกครั้ง (PATH เพิ่งอัปเดต) |
| ซับในไฟล์ส่งออกเป็นสี่เหลี่ยม/ไม่มีซับ | ffmpeg ไม่มี libass: `winget install --id Gyan.FFmpeg -e` แล้วเปิดโปรแกรมใหม่ |
| ถอดเสียงช้ามาก | ใช้โมเดล `medium` หรือ `small` และเลือกช่วงให้สั้นลง |
| `DLL load failed` ตอนถอดเสียง | ติดตั้ง Microsoft Visual C++ Redistributable: `winget install Microsoft.VCRedist.2015+.x64` |
| ดาวน์โหลดโมเดลล้มเหลว | ตรวจอินเทอร์เน็ต แล้วลองกดสร้างซับอีกครั้ง (ดาวน์โหลดต่อได้) ระหว่างดาวน์โหลดจะเห็นเปอร์เซ็นต์ที่แถบด้านบน กด "ยกเลิก" ได้ |
| โหลดโมเดลไม่ขึ้นเมื่อชื่อผู้ใช้ Windows เป็นภาษาไทย | ตั้ง `VIDCUT_MODEL_DIR` เป็นโฟลเดอร์ชื่อภาษาอังกฤษ เช่น `set VIDCUT_MODEL_DIR=C:\VidcutModels` ก่อนรัน `run.bat` |
| ส่งออกคลิปที่ตัดเยอะ (หลายสิบจุด) ช้าลง | ปกติ โปรแกรมแบ่งส่งออกเป็นชุด ๆ เพื่อไม่ให้ใช้ความจำเกิน แล้วค่อยรวมและฝังซับตอนท้าย |
| กด "ล้างไฟล์ชั่วคราว" แล้วบอกว่ามีงานทำอยู่ | รอให้งานเบื้องหลังเสร็จหรือกดยกเลิก แล้วลองใหม่ |
| เปิดโปรแกรมไม่ได้ พอร์ตถูกใช้อยู่ | ก่อนรัน `run.bat` ให้ตั้ง `set VIDCUT_PORT=8800` |
| หน้าต่างเลือกไฟล์ไม่ขึ้น | ใช้ "วางพาธไฟล์แทน" (คลิกขวาที่ไฟล์ > Copy as path) |
| ล้างไฟล์ชั่วคราว | โปรแกรมเก็บไฟล์พรีวิวไว้ที่ `VidcutProjects\default\proxies` ลบได้เมื่อไม่ใช้แล้ว |

## สถานะการทดสอบ (อ่านก่อนใช้งานจริง)

พัฒนาและทดสอบอัตโนมัติบน Linux: ตรรกะหลัก การตัดคำไทย การสร้างซับ การส่งออกด้วย ffmpeg และหน้าเว็บ (ด้วยเบราว์เซอร์จริง ใช้ Whisper จำลอง) **สิ่งที่ยังไม่เคยรันจริง** คือ `setup.bat`/`run.bat` บน Windows, การถอดเสียงด้วยโมเดล Whisper จริง และความเร็วบน CPU เครื่องนี้ ถ้าเจอปัญหาตรงนี้ถือเป็นเรื่องปกติของรอบแรก แจ้งข้อความ error ที่เห็นได้เลย

ยังไม่มี: การแก้คำผิด/ตัดช่วงพูดผิดด้วย LLM, การบันทึกสไตล์ซับเป็น preset ของตัวเอง, พรีวิวพื้นหลังเบลอแบบสด (ดูได้ที่ "ตรวจเฟรมจริง")
