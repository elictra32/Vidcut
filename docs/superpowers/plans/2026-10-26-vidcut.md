# Vidcut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local Windows web app that cuts long Thai videos to short TikTok/YouTube clips with auto Thai subtitles, dead-air removal and a subtitle editor, with no LLM/token use at run time.

**Architecture:** `core/` holds pure, unit-tested logic (time mapping, silence, Thai line-building, ASS, ffmpeg export, Whisper wrapper). `server/` is thin FastAPI glue with a background job runner. `web/` is build-less ES-module HTML/JS. Subtitles are anchored to source time; edited time is always derived.

**Tech Stack:** Python 3.11/3.12, FastAPI + uvicorn, faster-whisper (CPU, int8), PyThaiNLP (`newmm`), numpy, ffmpeg/ffprobe (libass), pytest, Node 22 (`node --test`, Playwright) for dev-time JS and UI tests only.

**Spec:** `docs/superpowers/specs/2026-10-26-vidcut-design.md`

## Global Constraints

- Python 3.11 or 3.12; Windows 11 is the only supported runtime; the server binds `127.0.0.1` only.
- Source media is never modified or copied; projects store paths.
- Core pipeline contains no LLM code and no network calls except the Whisper model download.
- `core/` never imports `server/` or `web/`.
- Silence defaults: `noise_db=-35`, `min_silence=0.6`, `padding=0.15`; audio analysed at 16 kHz mono.
- Whisper: `language="th"`, `word_timestamps=True`, `vad_filter=True`, `compute_type="int8"`, default model `large-v3`, selectable `medium`, `small`.
- Presets: TikTok 1080×1920, YouTube 1920×1080; both max 2 subtitle lines on screen; output MP4 H.264 + AAC plus `.srt`.
- ffmpeg export runs with `cwd` = a temp work dir and references the ASS file and `fonts` dir by relative name (Windows path escaping).
- User-facing errors are Thai messages with a suggested fix; ffmpeg stderr tail goes in a "details" field.
- `project.json` is written atomically (temp file + rename).
- Tests must not need real video or a Whisper model (synthetic clips from ffmpeg; Whisper injected); the real-model test is marked `slow` and skipped by default.

## Review Focus

1. **Clip with no audio track:** detect/transcribe say "ไม่พบเสียงในคลิปนี้" instead of crashing; export still works (silent audio is synthesized). Pinned in Tasks 3, 6, 7.
2. **File names with spaces/Thai characters/backslashes:** probe, silence, export and the subtitles filter all work. Pinned in Task 6.
3. **Whisper returns no speech (silence/music):** returns an empty list; UI shows "ไม่พบเสียงพูด", never an empty editor. Pinned in Task 7.
4. **Empty/invalid cut state:** all keeps disabled, selection with `start >= end`, or selection beyond the edited duration gives a clear error, not an ffmpeg crash. Pinned in Tasks 2 and 6.
5. **Phone clips with rotation metadata / odd frame rate:** `probe` reports display width/height after rotation so 9:16 framing is right. Pinned in Task 1.
